# Dataset card: <dataset name>

Fill this in before any training or fine-tuning run. If a field is unknown,
write "unknown" and treat that as a risk, not a detail.

## Purpose
What model behaviour this dataset is meant to create or improve, and the
eval that will prove it worked.

## Source
- Where the data came from (product logs, support chats, public sources,
  synthetic generation, manual writing)
- Licence and consent basis for using it this way
- Date range and collection method

## Composition
- Number of examples, and the split (train / validation / test)
- Fields per example and their meaning
- Label definitions, with one example of each label

## Cleaning
- Deduplication method
- PII handling: what was removed or masked, and how you verified it
- Known noise that remains

## Bias and gaps
- Groups, languages, or cases that are under-represented
- Cases the dataset deliberately excludes

## Maintenance
- Owner
- Refresh cadence and what triggers a rebuild
- Version history (version, date, what changed)
